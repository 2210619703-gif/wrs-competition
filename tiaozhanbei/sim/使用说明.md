# 执行模块使用说明（当前为仿真）

执行模块现在只有仿真，没有真机。输入是决策生成的任务 JSON，输出是机械臂在场景里完成抓放。

日常展示仍走决策界面 `python tiaozhanbei/decision/agent_demo_ui.py`（界面会调用本目录脚本）。也可以不经过界面、只喂 JSON。

---

## 1. 需要什么

- 已能运行本仓库 WRS / Panda3D 仿真（与采集 `dataset_learn` 同一套环境）
- 决策 JSON，例如 `tiaozhanbei/tasks/delivery_agent_auto.json`
- 场景数据：`tiaozhanbei/dataset_learn/`（螺丝入格用 **0502**，原 `ec/0001`）
- 零件模型：`tiaozhanbei/Part_Model/`（料盘为 `Fixtures/Trays/box.stl`）

不需要 Dify、不需要显卡训练。

---

## 2. 标准抓放

仓库根目录：

```bash
python tiaozhanbei/sim/run_agent_pick_place_side_sim.py
python tiaozhanbei/sim/run_agent_pick_place_side_sim.py --task tiaozhanbei/tasks/test06.json
```

窗口里空格播放动画。`--no-anime` 只规划不播。

---

## 3. 喇叭头螺丝入格

```bash
python tiaozhanbei/sim/ec/run_ec_bin_sim.py
python tiaozhanbei/sim/ec/run_ec_bin_sim.py --task tiaozhanbei/sim/ec/tasks/test03.json
```

默认样本 `dataset_learn/0502`。别名 `ec0001` / `ec/0001` 在决策侧仍指向这一组。

---

## 4. 和决策界面的关系

界面写死调用：

- `sim/run_agent_pick_place_side_sim.py`
- `sim/ec/run_ec_bin_sim.py`

任务 JSON 默认仍写到 `tiaozhanbei/tasks/delivery_agent_auto.json`。

---

## 5. 不要放进本模块的东西

- `tiaozhanbei/dataset_gen/`：生成 / 修补 `dataset_learn`
- `yolo/`（感知）、`decision/`（决策）

真机代码以后再整理进本目录。
