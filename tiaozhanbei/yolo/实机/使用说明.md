# 实机：采集与推理

真实桌面零件。**不要使用 `../仿真/best.pt`。**

## 本目录有什么

| 文件 | 作用 |
|------|------|
| `take_picture.py` | RealSense 采集 RGB、对齐深度、点云 |
| `train_real_merged_yolo.py` | **真实数据训练**（单件+多件合并，113 类；对应交件实验 `train-real-merged-seg-2`） |
| `train_parts_yolo.py` | 通用训练入口（同一套 `dataset/`） |
| `live_detect_realsense_d405.py` | D405 实时分割预览 |
| `yolo26s-seg.pt` | 官方分割预训练 |
| `best.pt` | 已训好的真实权重（`train-real-merged-seg-2` 的拷贝） |
| `dataset/` | 113 类全量：`data.yaml` + `images/` + `labels/`（train 3884 / val 975） |
| `classes.txt` | 113 类英文名 |
| `infer_seg_annotations.py` | 对真实图做分割推理 |
| `annotations_to_vision.py` | 转成决策用的短 JSON |

## 1. 环境

需要 Intel RealSense 相机与驱动。仓库根目录：

```bash
pip install -r tiaozhanbei/yolo/实机/requirements.txt
```

`torch` 请按本机 CUDA 版本另行安装。

## 2. 采集

```bash
python tiaozhanbei/yolo/实机/take_picture.py
```

或在本目录执行 `python take_picture.py`。

- 分辨率 1280×720，深度对齐到彩色
- 内参写入保存目录下的 `camera.json`
- 按 **s** 保存一帧：`rgb/000000.png`、`depth/000000.png`、`pointcloud/000000.ply`
- 按 **q** 退出

默认保存目录在脚本里的 `save_dir`。换零件时改这一行再采。

深度图为 16 位 PNG。推理若要用米制深度，用 `camera.json` 的 `depth_scale` 把像素值乘成米（或另存 `depth_m.npy`）。

## 3. 对刚采的图做检测

```bash
python infer_seg_annotations.py --image "Drywall bugle screws_001/rgb/000000.png" --weights best.pt --pretty --save-masks
python annotations_to_vision.py --ann "Drywall bugle screws_001/rgb/yolo_annotations.json"
```

`--weights` 必须是本目录的 `best.pt`。类名见 `classes.txt`。

## 4. 训练（113 类真实分割）

本目录 `dataset/` 已含合并全量（单件 + 多件，train 3884 / val 975）。`data.yaml` 的 `path` 为本目录相对路径 `.`。

检查数据（不开始训）：

```bash
python train_real_merged_yolo.py
```

有 GPU 时按交件同设置训练（从 `yolo26s-seg.pt` 起步，100 epoch）：

```bash
python train_real_merged_yolo.py --train --device 0
```

从本目录已有真实权重继续微调：

```bash
python train_real_merged_yolo.py --train --model best.pt --device 0 --epochs 50
python train_parts_yolo.py --train --device 0 --epochs 100 --batch 8
```

训完权重在 `runs/segment/train-real-merged-seg-2/weights/best.pt`（或 `train-parts-yolo-seg`），可拷回覆盖本目录 `best.pt`。

## 5. 和仿真感知的区别

| | 实机 | 仿真 |
|--|------|------|
| 采集 | 本目录 `take_picture.py` | `tiaozhanbei/dataset_gen/` |
| 训练 | `train_real_merged_yolo.py`（113 英文类，合并集） | `仿真/train_annotations_yolo.py`（124 中文类） |
| 权重 | 本目录 `best.pt` | `仿真/best.pt` + 可选 `tiny19` |
| 状态头 | 默认不用仿真状态头 | 可加载 `仿真/权重/state-head-yolo26.pt` |
