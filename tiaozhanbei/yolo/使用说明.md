# 感知模块使用说明

本模块对应赛项感知：用分割模型认出零件，再补深度与位姿，写成决策 / 仿真能读的 JSON。

**仿真权重和实机权重不要混用。**

| 子目录 | 相机 | 权重 | 类别 |
|--------|------|------|------|
| `仿真/` | 自研仿真场景图 + 深度 | `仿真/best.pt`（124 类）；可选 `仿真/权重/yolo26s-seg-tiny19.pt` 小件补检 | 124 类中文细类 |
| `实机/` | Intel RealSense | `实机/best.pt` | 113 类英文 |

`仿真/best.pt` 与 `仿真/权重/yolo26s-seg-fine.pt` 是同一套 124 类主干。决策界面默认用 `best.pt`。只要 `tiny19` 在，推理会自动补检小螺丝/铆钉/垫圈；只要主干就加 `--no-small`。

造仿真数据不在本目录，见 `tiaozhanbei/dataset_gen/`。场景图在 `tiaozhanbei/dataset_learn/`。展示样例与实机全量见 `数据集展示.md`。

日常展示由决策界面调用仿真推理，不必单独开本目录。

---

## 1. 仿真推理（评委最快验证）

仓库根目录：

```bash
pip install -r tiaozhanbei/yolo/仿真/requirements.txt
python tiaozhanbei/yolo/仿真/infer_seg_annotations.py --sample 0001 --save-masks --pretty
python tiaozhanbei/yolo/仿真/annotations_to_vision.py --ann tiaozhanbei/yolo/仿真/outputs/0001.json
```

打开展示样例（不经 `dataset_learn`）：

```bash
python tiaozhanbei/yolo/仿真/infer_seg_annotations.py --image tiaozhanbei/yolo/仿真/数据样例/0001/0001.jpg --pretty --save-masks
```

- `--sample 0001` 读取 `dataset_learn/0001` 的图和深度
- 最终 JSON：`仿真/outputs/0001.json`（字段对齐仿真标注）
- 界面启动仿真时用：`仿真/sim_dataset/`

YOLO 本身只出 2D 框和轮廓。位置、朝向、点云由深度图和相机参数算出，不是权重直接训出来的。

---

## 2. 仿真训练（需要时再跑）

```bash
python tiaozhanbei/yolo/仿真/train_annotations_yolo.py --train
python tiaozhanbei/yolo/仿真/export_dataset_learn_state_cls.py
python tiaozhanbei/yolo/仿真/train_state_head.py --train
```

或：`python tiaozhanbei/yolo/仿真/train_dataset_learn_seg.py --train --fine-grained`

需要 GPU。类别名见 `仿真/类别配置/`。

---

## 3. 实机采集与推理

需要 Intel RealSense。详细步骤见 `实机/使用说明.md`。

```bash
pip install -r tiaozhanbei/yolo/实机/requirements.txt
python tiaozhanbei/yolo/实机/take_picture.py
python tiaozhanbei/yolo/实机/infer_seg_annotations.py --image <刚采的 rgb 图> --weights tiaozhanbei/yolo/实机/best.pt --pretty --save-masks
python tiaozhanbei/yolo/实机/live_detect_realsense_d405.py
```

113 类全量在 `实机/dataset/`（train 3884 / val 975）。复训与交件实验一致：

```bash
python tiaozhanbei/yolo/实机/train_real_merged_yolo.py --train --device 0
```

---

## 4. 和决策、执行的关系

界面 `decision/agent_demo_ui.py` 调用 `仿真/infer_seg_annotations.py`，把结果写成与 `dataset_learn` 同结构的 JSON，再交给智能体和仿真。执行模块不区分这份 JSON 来自标注还是检测。
