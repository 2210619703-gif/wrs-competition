# 数据集展示

仿真全量在仓库 `tiaozhanbei/dataset_learn/`（数千张不重复塞进本目录）。本目录另放两份展示样例。**实机 113 类全量在** `实机/dataset/`。

造数、零件 STL、WRS 仿真分别在 `tiaozhanbei/dataset_gen/`、`tiaozhanbei/Part_Model/`、仓库根目录 `wrs/`，不要在本目录再拷一份。

---

## 本目录里有什么

| 展示位置 | 用途 | 规模 |
|----------|------|------|
| [`仿真/数据样例/0001`](仿真/数据样例/0001) | 多物体桌面（仿真 RGB-D + 标注） | 4 个零件 |
| [`仿真/数据样例/1612`](仿真/数据样例/1612) | 单物体（中等零件） | 1 个零件 |
| [`仿真/决策微调数据`](仿真/决策微调数据) | 给决策 / 大模型的 `vision_objects` 样例 | 若干 JSON |
| [`仿真/类别配置`](仿真/类别配置) | 仿真 124 类中文名 | 类表 |
| [`仿真/权重/yolo26s-seg-tiny19.pt`](仿真/权重) | 19 类近景小件补检（螺丝/铆钉/垫圈/滑动轴承） | 与 124 类主干配合 |
| [`实机/dataset/`](实机/dataset/) | 实机 113 类 YOLO-seg 全量（单件 + 多件合并） | train 3884 / val 975 |

日常推理仍读 `dataset_learn/`；`数据样例` 只给评委打开看标注字段。

---

## 1. 仿真多物体：`0001`

打开：`仿真/数据样例/0001/0001.jpg`（预览图 `0001_labeled.png`）。

| 文件 | 说明 |
|------|------|
| `0001.jpg` | RGB，1280×720 |
| `depth_m.npy` | 深度，单位米 |
| `annotations.json` | 真值：类别、框、多边形、mask、pose_6d、state |
| `masks/` | 逐物体二值分割 |
| `pointcloud.ply` | 场景点云 |
| `yolo_annotations.json` | 感知推理输出（与真值同字段） |
| `vision_objects.json` | 转给决策侧的短 JSON |

图中 4 个零件：轴承-凸轮滚轮、机器工具-螺丝刀、螺母-焊接螺母、螺钉螺栓-圆柱头螺栓。

---

## 2. 仿真单物体：`1612`

打开：`仿真/数据样例/1612/1612.jpg`（预览图 `1612_labeled.png`）。

一类一个中等零件：`轴承-四点接触球轴承`（约 245×216 像素），用于展示单件细分类标注（框 + mask + 位姿）。

---

## 3. 决策微调数据（工业 JSON）

目录：`仿真/决策微调数据/`。

| 文件 | 说明 |
|------|------|
| `vision_objects.json` | 由 `0001` 转出的决策输入（124 中文细类） |
| `vision_objects_empty.json` | 空场景 `[]` |
| `perception_annotations.json` | 感知完整 JSON |
| `gt_annotations.json` | 对应真值 |
| `VISION_API.md` | 当前接口（不是旧 8 类英文） |

决策侧微调不需要再拷图像，用这些 JSON 即可看接口。

---

## 4. 实机全量：`实机/dataset/`

113 类英文 YOLO-seg（单件 + 多件合并），与交件权重 `train-real-merged-seg-2` 对应。

```
实机/dataset/
  data.yaml          path: .   nc: 113
  classes.txt
  images/train       3884 张
  images/val         975 张
  labels/train
  labels/val
```

单件图沿用原文件名（如 `acorn_nuts__000000.png`），多件场景带 `scene_` 前缀。现场另采可用 `实机/take_picture.py`。
