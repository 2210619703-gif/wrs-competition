# 挑战杯作品使用说明

本文给评委用：先搭运行环境，再按文件夹操作。所有命令在仓库根目录 `wrs-main-competition` 下执行。

更细的参数见各模块自己的说明，文末有目录。

---

## 1. 环境（Docker）

`tiaozhanbei/docker/` 提供仿真运行环境：Python、依赖、以及和本仓库一致的目录布局。镜像含代码与 `wrs/`，不含全量场景数据。

### 1.1 下载并放置仿真数据

全量场景不在镜像和本仓库里，从网盘下载后解压再放：

- 文件：`dataset_learn.zip`
- 链接：https://pan.baidu.com/s/1tIX-LPbA6K2ZrWNOgFu_fQ?pwd=mxnd
- 提取码：`mxnd`

步骤：

1. 打开上面的链接，输入提取码 `mxnd`，下载 `dataset_learn.zip`。
2. 解压。解压后必须得到名为 `dataset_learn` 的文件夹，里面**直接**是样本号目录（`0001`、`0501`、`0502` …），不要多套一层，也不要把 zip 本身放进工程当数据用。
3. 把该文件夹放到本工程里，使路径为：

```
tiaozhanbei/dataset_learn/
  0001/   0501/   0502/   …     每个样本一册：RGB、深度、annotations.json
```

演示至少确认这两份存在：

- `tiaozhanbei/dataset_learn/0501/annotations.json`（标准抓放）
- `tiaozhanbei/dataset_learn/0502/annotations.json`（螺丝入格）

数据解压在别的盘时，不要改代码：Docker 启动把该目录挂到 `/app/tiaozhanbei/dataset_learn`（见 1.2 节的 `DATASET_LEARN`）。本机直接跑界面时，仍须出现在 `tiaozhanbei/dataset_learn/`，或在该位置做目录链接。`Part_Model/` 留在原位置，不要挪走。

### 1.2 构建并启动

在仓库根目录：

```bash
docker build -f tiaozhanbei/docker/Dockerfile -t tiaozhanbei-sim .
```

Windows PowerShell：

```powershell
$env:DATASET_LEARN="解压后的 dataset_learn 绝对路径"
docker compose -f tiaozhanbei/docker/compose.yml up --build
```

`DATASET_LEARN` 指向的目录里必须直接是 `0001`、`0501`、`0502` 等。compose 默认跑标准抓放样本 `0501`（`--no-anime`）。

本机已装 Python 时，演示界面也可不经容器，直接从第 4 节开始。智能体（Dify）的 Docker 与本节不是同一套，见 `decision/使用说明.md` 第 1～3 节。

## 2. 各文件夹怎么用

```
tiaozhanbei/
  yolo/          感知。仿真图和实机图的分割推理、训练脚本、权重、展示样例
  decision/      决策。语音或打字下指令，生成任务 JSON，并拉起仿真界面
  sim/           执行（仿真）。读任务 JSON，在 Panda3D 里规划并播放抓放
  real/          执行（真机）。D405 识别、限位适配、向机械臂下发
  dataset_gen/   生成或修补仿真场景数据，日常演示不用打开
  Part_Model/    零件与料框 STL，仿真摆件时读取，不要改路径
  tasks/         决策写出的任务 JSON，仿真默认从这里读
  textures/      仿真桌面纹理
  docker/        仿真运行环境，按第 1 节使用
```

场景数据按第 1.1 节放到 `dataset_learn/`。仓库根目录的 `wrs/` 是仿真运动学与可视化，和 `tiaozhanbei/` 一起使用，不要单独挪走。

模块交接顺序：

```
口令 → decision 任务 JSON
     → yolo 的 annotations.json（或直接用 dataset_learn 标注）
     → sim 规划并播放
     →（真机）real 适配后下发
```

| 文件夹 | 评委怎么用 |
|--------|------------|
| `yolo/` | 单独验证感知：对一张场景图推理，得到 JSON |
| `decision/` | 主界面：下指令、看任务 JSON、启动仿真 |
| `sim/` | 不经界面，直接喂 JSON 看机械臂动作 |
| `real/` | 工控机上验证真机；默认不往臂上发运动 |
| `dataset_learn/` | 仿真场景；只放置，不改内部文件 |
| `Part_Model/` | 被仿真自动读取 |
| `tasks/` | 查看或改任务 JSON 后再交给 `sim/` |
| `docker/` | 第 1 节：构建镜像并挂载 `dataset_learn` |

## 3. 本机依赖（不走 Docker 时）

### 3.1 安装本机依赖

Windows，Python 3.10 或更高，安装时勾选 Add to PATH。在仓库根目录执行：

```bash
pip install -r tiaozhanbei/decision/requirements.txt
pip install -r tiaozhanbei/yolo/仿真/requirements.txt
```

界面右侧预览图再执行：`pip install pillow`。

真机工控机再执行：

```bash
pip install -r tiaozhanbei/yolo/实机/requirements.txt
pip install -r tiaozhanbei/real/requirements.txt
```

### 3.2 使用智能体（可选）

不连智能体也可以演示：界面会走本地规则，照样出 JSON 并拉仿真。

要连 Dify 时，按 `decision/使用说明.md` 第 1～3 节：安装 Docker Desktop 与 Git，运行 `decision/启动Dify环境.bat`，导入 `decision/workflows/workflow.yml` 并发布，把 `app-` 密钥写入 `decision/agent_demo_ui.py` 开头的 `DIFY_API_KEY`。

### 3.3 使用真机（可选）

- fafu 臂与夹爪上电，串口按 `robot.cfg`
- 固定俯视 Intel RealSense D405
- 手眼文件 `real/handeye_d405.json`；没有时先运行 `real/hand_eye_calib.py`
- SDK 在仓库 `fafu_arm_sdk-main/fafu_robot_python`；不在该位置时设置环境变量 `FAFU_SDK_DIR`

## 4. 主入口

仿真和实机各一个界面入口。先改配置，再启动，运行后看日志和写出的 JSON。

### 4.1 仿真主入口

```bash
python tiaozhanbei/decision/agent_demo_ui.py
```

打开后：打字或录音发送 → 感知场景 → 生成任务 JSON → 拉起 Panda 窗口播放。标准抓放走 `sim/run_agent_pick_place_side_sim.py`，螺丝入格走 `sim/ec/run_ec_bin_sim.py`。

可先用：`拿取轴承-凸轮滚轮放到收纳盒` / `把所有零件放进收纳盒` / `把12个螺丝依次放到对应格子`。更多口令见 `decision/使用说明.md` 第 5 节。

**使用前改这些（都在 `decision/agent_demo_ui.py` 文件开头）：**

| 改什么 | 作用 | 怎么改 |
|--------|------|--------|
| `DIFY_API_URL` | 智能体地址 | 本机 Dify 保持 `http://localhost:8080/v1/workflows/run`。不要填网页上的 `/workflow/xxx` |
| `DIFY_API_KEY` | 智能体密钥 | 换成你工作流「访问 API」里 `app-` 开头的那一串。不改也能跑，会走本地规则 |
| `FORCE_START_SCENE` | 演示哪套场景 | `"ec_bin"` = 只演示螺丝入格；改成 `""` = 标准抓放入筐 |
| `FORCE_START_SAMPLE` | 标准场景样本号 | 当前 `"0501"`。改成 `"0001"` 为螺丝刀那组。仅在 `FORCE_START_SCENE` 为空时生效 |

数据按第 1.1 节放好。`0501` 入筐播 `sim/traj/0501_all_parts_traj.json`，EC 12 件播 `sim/ec/traj/ec_all12_traj.json`。

**运行后看这些：**

| 看什么 | 说明 |
|--------|------|
| 界面左侧日志 | `[JSON_SOURCE]` 是 Dify 还是本地规则；`[SIM]` 后面是实际拉起的命令 |
| `tiaozhanbei/tasks/delivery_agent_auto.json` | 标准抓放刚写出的任务 |
| `tiaozhanbei/sim/ec/tasks/delivery_ec_auto.json` | 螺丝入格刚写出的任务 |
| `tiaozhanbei/yolo/仿真/outputs/` | 本次感知 JSON |
| 右侧 / Panda 窗口 | 场景和机械臂动作 |

不经界面、只喂 JSON 时用第 5.3 节命令。

### 4.2 实机主入口

```bash
python tiaozhanbei/real/real_demo_ui.py
```

打开后机械臂先回避让位。界面或启动该程序的终端里打字回车发送，`q` 退出。默认不往臂上发运动。

**使用前改这些：**

| 改什么 | 在哪 | 怎么改 |
|--------|------|--------|
| `DIFY_API_URL` / `DIFY_API_KEY` | `real/real_demo_ui.py` 开头，或环境变量 | 与仿真同一套智能体时改成相同值 |
| 「允许真机执行」 | 界面复选框 | 不勾 = 只规划、打印，臂不动。确认日志无误后再勾 |
| `FAFU_SDK_DIR` | 系统环境变量 | SDK 不在仓库 `fafu_arm_sdk-main/fafu_robot_python` 时必须设置 |
| `PLACE_CONF_DEG` | `real/real_config.py` | 料框示教关节角（度）。换料框位置后按现场重标 |

串口、软限位看 SDK 目录下的 `robot.cfg`，不要改仿真里的关节范围来代替它。

**运行前确认这些文件在：**

| 文件 | 作用 |
|------|------|
| SDK 的 `robot.cfg` | 串口与软限位 |
| `real/handeye_d405.json` | 手眼。没有则先跑 `python tiaozhanbei/real/hand_eye_calib.py` |
| `real/gripper_calib.json` | 夹爪开口换算。没有则先跑 `python tiaozhanbei/real/calibrate_gripper.py --execute` |
| `real/real_multi.pt` 或 `yolo/实机/best.pt` | 实机分割权重，不要用仿真 `yolo/仿真/best.pt` |

**运行后看这些：**

| 看什么 | 说明 |
|--------|------|
| 界面 / 终端日志 | `[JSON_SOURCE]`、识别类别、是否 dry-run |
| `tiaozhanbei/real/outputs/traj.json` | 仿真规划出的关节轨迹 |
| `tiaozhanbei/real/outputs/plan.json` | 适配真机限位后的动作脚本 |
| `tiaozhanbei/real/outputs/vision/` | 当次抓帧与 `annotations.json` |

先自检再界面：`python tiaozhanbei/real/check_offline.py`。命令行 dry-run / `--execute` 见第 5.4 节。

## 5. 分文件夹操作

### 5.1 `yolo/` 感知

仿真权重：`yolo/仿真/best.pt`（124 类中文）。可选小件补检：`yolo/仿真/权重/yolo26s-seg-tiny19.pt`。  
实机权重：`yolo/实机/best.pt` 或 `real/real_multi.pt`（113 类英文）。两套不要混用。

对仿真样本 `0001` 推理：

```bash
python tiaozhanbei/yolo/仿真/infer_seg_annotations.py --sample 0001 --save-masks --pretty
python tiaozhanbei/yolo/仿真/annotations_to_vision.py --ann tiaozhanbei/yolo/仿真/outputs/0001.json
```

结果在 `yolo/仿真/outputs/`。展示样例与实机全量数据见 `yolo/数据集展示.md`。实机采图与推理见 `yolo/使用说明.md` 第 3 节。

### 5.2 `decision/` 决策

在 `tiaozhanbei/decision` 目录：

```bash
python agent_demo_ui.py
python agent/demo_voice_agent.py --cmd "拿取轴承-凸轮滚轮放到收纳盒" --sample 0001
```

不启动界面、只用本地规则：

```bash
python offline/build_tasks_local.py
```

写出的任务默认在 `tiaozhanbei/tasks/delivery_agent_auto.json`。收纳盒世界坐标为 `[0.30, -0.20, 0.0]`。

### 5.3 `sim/` 仿真执行

不经界面、直接喂 JSON：

```bash
python tiaozhanbei/sim/run_agent_pick_place_side_sim.py
python tiaozhanbei/sim/run_agent_pick_place_side_sim.py --task tiaozhanbei/tasks/test06.json
python tiaozhanbei/sim/run_agent_pick_place_side_sim.py --task tiaozhanbei/tasks/delivery_agent_auto.json --no-anime
```

螺丝入格：

```bash
python tiaozhanbei/sim/ec/run_ec_bin_sim.py
python tiaozhanbei/sim/ec/run_ec_bin_sim.py --task tiaozhanbei/sim/ec/tasks/test03.json
```

`--no-anime`、`--export-traj` 只规划并导出关节轨迹，供真机复用。轨迹叠影：

```bash
python tiaozhanbei/sim/render_full_trajectory.py --sample-id 0001 --object 螺丝刀 --stage approach
python tiaozhanbei/sim/render_full_trajectory.py --sample-id 0001 --object 螺丝刀 --stage pick
python tiaozhanbei/sim/render_full_trajectory.py --sample-id 0001 --object 螺丝刀 --stage depart
python tiaozhanbei/sim/render_full_trajectory.py --sample-id 0001 --object 螺丝刀 --stage place
```

脚本参数见 `sim/使用说明.md`。

### 5.4 `real/` 真机执行

1. 离线自检：

```bash
python tiaozhanbei/real/check_offline.py
```

2. 先 dry-run（不发运动），再加 `--execute`：

```bash
python tiaozhanbei/real/run_task_real.py --task tiaozhanbei/tasks/delivery_agent_auto.json
python tiaozhanbei/real/run_task_real.py --task tiaozhanbei/tasks/delivery_agent_auto.json --execute --speed 8
```

3. 现场视觉一条龙：

```bash
python tiaozhanbei/real/run_vision_real.py
```

4. 带界面（启动后机械臂先回避让位）。默认不勾「允许真机执行」。口令含「放到 / 放进 / 收纳盒 / 料框」时，每件抓完放到示教料框；只说抓、不说放时，夹着回避让位等下一条。终端里也可以打字回车发送，`q` 退出。

```bash
python tiaozhanbei/real/real_demo_ui.py
```

没有相机时用已存帧：

```bash
python tiaozhanbei/real/d405_camera.py --save-dir tiaozhanbei/real/outputs/frame01
python tiaozhanbei/real/real_demo_ui.py --frame-dir tiaozhanbei/real/outputs/frame01
```

标定各做一次：

```bash
python tiaozhanbei/real/hand_eye_calib.py
python tiaozhanbei/real/calibrate_gripper.py --execute
```

安全与限位见 `real/README.md`。

### 5.5 `dataset_gen/` 造数

日常演示不必运行。需要重新生成或修补 `dataset_learn` 时，在该目录执行采集 / 修补脚本，输出仍写到 `tiaozhanbei/dataset_learn/`。

### 5.6 `tasks/` 任务 JSON

决策界面会覆盖写入这里。也可以打开已有 JSON，再用第 5.3 节命令交给仿真。

## 6. 训练（复现模型时再做）

需要 GPU。仿真分割与姿态头：

```bash
python tiaozhanbei/yolo/仿真/train_annotations_yolo.py --train
python tiaozhanbei/yolo/仿真/export_dataset_learn_state_cls.py
python tiaozhanbei/yolo/仿真/train_state_head.py --train
```

实机分割与交件实验一致：

```bash
python tiaozhanbei/yolo/实机/train_real_merged_yolo.py --train --device 0
```

也可用 `yolo/实机/train_parts_yolo.py`。步骤见 `yolo/实机/使用说明.md`。
